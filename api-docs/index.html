명세를 불러오는 중입니다…

로컬 백엔드 실행

php -S 127.0.0.1:8080 -t backend/public

MySQL이 필요하면 `docker compose up -d` 후 `php backend/bin/migrate.php`를 먼저 실행합니다.

이 문서는 저장소의 public/openapi.json을 단일 소스로 씁니다. 명세를 고치면 페이지가 그대로 반영하고, 단위 테스트가 `backend/public/index.php`의 라우트와 명세 경로가 어긋나지 않았는지 확인합니다. 인증·레이트 리밋·SENS 실발송은 운영 배포 단계의 항목이며, 현재 명세는 로컬 데모 범위입니다.
