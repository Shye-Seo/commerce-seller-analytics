발송 버튼을 누르면 템플릿 변수로 채운 실제 본문이 여기에 나타납니다.

본문은 카카오에 검수된 템플릿과 같은 형식이며, 변수에는 개행을 넣지 않습니다. 상한은 1,000자입니다. 서명(x-ncp-apigw-signature-v2)은 서버에서 HMAC-SHA256으로 만들고, 이 화면은 그 값을 흉내 내지 않습니다.

발송 이력 타임라인

총 0건 · 성공 0 · 실패 0 · 불확실 0 · 성공률 0%

발송 이력이 없습니다. 이상 알림이나 배치 요약을 한 번 보내 보세요.

상태 전이는 DB 스키마와 같습니다: queued → accepted(202) → delivered(0000) / failed. 3005(수신 결과 불확실)는 성공으로 세지 않고 sent로 남깁니다. 재시도는 3회까지이며, 템플릿·서명 오류는 재시도해도 성공하지 않습니다. 이력은 브라우저에만 저장되고 서버로 전송되지 않습니다.

계약 프리셋은 공개된 수수료 정책을 참고한 데모 값이며, 실제 계약서 값과 다를 수 있습니다. 데모 원장은 고정 시드로 생성해 같은 조건이면 같은 결과가 나옵니다. 마스킹은 화면 표시에만 적용되고 원본 데이터는 변경되지 않습니다.
